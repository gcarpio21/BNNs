NOTEBOOK 1: bnn_laplace_visualization.ipynb
Location: ./laplace_torch/bnn_laplace_visualization.ipynb
================================================================================

PURPOSE AND OBJECTIVES
  Demonstrates Bayesian inference on neural networks using Laplace approximation.
  Trains a NN on sinusoidal regression data and uses Laplace to quantify uncertainty.

SECTION BREAKDOWN
  Section 1 - Import Required Libraries:
    Imports numpy, torch, matplotlib, laplace.Laplace, laplace.marglik_training,
    laplace.curvature.backpack.BackPackGGN. Sets random seeds.
  
  Section 2 - Set Up Data and Configuration:
    Configures n_epochs=1000, batch_size=32, sigma_noise=0.3.
    Loads/generates sinusoidal regression data.
  
  Section 3 - MAP Training and Laplace Approximation:
    Defines network 1->50->1 with Tanh.
    Trains MAP with Adam + MSE loss.
    Fits Laplace approximation. Optimizes hyperparameters (prior precision, noise)
    via marginal likelihood.
  
  Section 4 - Generate Predictions:
    Generates predictions using Laplace, computes marginal and joint predictive
    distributions, calculates total predictive uncertainty.
  
  Section 5 - Visualize Results:
    Creates regression plots showing predictions with uncertainty bands,
    training loss (log scale), marginal likelihood optimization, uncertainty
    decomposition (epistemic vs aleatoric).
  
  Section 6 - Compare Multiple Runs:
    Runs parametric study with noise levels 0.1, 0.3, 0.5.
  
  Section 7 - Save and Export Results:
    Saves model state, predictions, and summary statistics to files.

LIBRARIES USED
  numpy: Numerical computations and arrays
  torch: Neural network building and training
  matplotlib.pyplot: Plotting
  laplace.Laplace: Laplace approximation object
  laplace.marglik_training: Marginal likelihood optimization
  laplace.curvature.backpack.BackPackGGN: Curvature approximation

KEY METRICS
  Training Loss (MSE): How well the MAP model fits training data
  Marginal Likelihood: Hyperparameter optimization objective (higher = better)
  Learned sigma_noise: Estimated data noise
  Learned prior precision: Inverse of prior variance
  Epistemic std: Model uncertainty from Laplace (varies with input)
  Aleatoric std: Irreducible data noise
  Total predictive std: sqrt(epistemic^2 + aleatoric^2)

RESULTS
  Laplace captures both epistemic and aleatoric uncertainty.
  Uncertainty bands widen in extrapolation regions with less data.
  True function falls within uncertainty bands.
  Marginal likelihood optimization converges successfully.

LAPLACE IMPLEMENTATION
  Laplace(model, "regression", subset_of_weights="all", hessian_structure="full")
  la.fit(train_loader) - computes Hessian at MAP weights
  la.log_marginal_likelihood() - optimizes hyperparameters
  la(X_test) - returns (mean, variance) via closed-form GLM

    Creates DataLoaders, saves raw dataset figure.
  
  Cell 4 (Model Architecture):
    Defines TinyMLP: 2->64->Tanh->64->Tanh->2.
    Reports ~8k parameters.
  
  Cell 5 (MAP Training):
    Trains MAP with Adam (lr=1e-3, weight_decay=1e-4), CrossEntropyLoss.
    300 epochs, measures fit/test time, saves training loss figure.
  
  Cell 6 (Helper Functions):
    plot_boundary - visualizes decision boundaries.
    uncertainty_map - visualizes epistemic uncertainty.
    make_scatter_comparison - standardized scatter plots.
  
  Cell 7 (MAP Prediction):
    map_predict function, saves decision boundary figure.
  
  Cell 8 (Laplace Diag GridSearch):
    Creates Laplace with diagonal Hessian + grid search prior precision.
  
  Cell 9 (Laplace Diag GridSearch Prediction):
    la_predict helper, saves decision boundary figure.
  
  Cell 10 (MAP vs Laplace Comparison):
    Side-by-side boundary and uncertainty plots.
  
  Cell 11 (Laplace Diag MargLik):
    Same as Cell 8 but uses marginal likelihood for tuning.
  
  Cell 12 (Three-Way Comparison):
    MAP vs Laplace(diag,grid) vs Laplace(diag,marglik).
  
  Cell 13 (Three-Way Analysis):
    Per-sample analysis, confidence distributions, uncertainty distributions.
  
  Cell 14 (Laplace Full MargLik):
    Laplace with full Hessian + marginal likelihood.
  
  Cell 15 (Diag vs Full Boundary):
    decision boundaries + uncertainty of diag vs full.
  
  Cell 16 (Diag vs Full Analysis):
    Per-sample comparison.
  
  Cell 17 (Laplace Kron MargLik):
    Laplace with Kron/KFAC Hessian.
  
  Cell 18 (Three Hessian Comparison):
    Diag vs Full vs Kron boundaries + uncertainty.
  
  Cell 19 (Three Hessian Analysis):
    Per-sample comparison across all three.
  
  Cell 20 (Export):
    DataFrame metrics, CSV export, LaTeX table code.
  
  Cell 21 (LaTeX References):
    Figure mapping for LaTeX inclusion.

LIBRARIES USED
  torch: NN modules, training
  sklearn.datasets.make_moons: Generates the dataset
  sklearn.model_selection.train_test_split: Data splitting
  sklearn.preprocessing.StandardScaler: Feature normalization
  numpy: Numerical ops
  pandas: Metrics table
  matplotlib: All visualizations
  laplace.Laplace: Core Laplace implementation

KEY METRICS
  Fit_Time (s): Time to fit Laplace Hessian
  Tune_Time (s): Time to tune prior precision
  Inf_Time (s): Inference time on test set
  Accuracy: Classification accuracy
  Prior_Precision: Optimized prior precision value

RESULTS
  All methods achieve ~87-88% accuracy.
  Laplace assigns higher uncertainty between the two moons.
  Diagonal fastest but ignores correlations.
  Full most accurate covariance but expensive.
  Kron provides middle ground.
  Grid search vs marginal likelihood yield different prior precisions.

LAPLACE IMPLEMENTATION
  Laplace(model, 'classification', subset_of_weights='all', hessian_structure='diag'/'full'/'kron')
  la.fit(train_loader)
  la.optimize_prior_precision(method='gridsearch', val_loader=val_loader) or method='marglik'
  la(test_batch, pred_type='glm', link_approx='probit')
  Uses GLM approximation with probit link for tractable classification predictions.

16 figures saved to ./laplace_torch/figures/

Location: ./laplace_torch/bnn_bayesian_torch.ipynb
================================================================================

PURPOSE AND OBJECTIVES
  BNN using Bayesian-Torch (Intel Labs) with SVI via ELBO optimization.
  Shows MOPED initialization from MAP, Flipout layers, MC sampling for uncertainty.

SECTION BREAKDOWN
  
  Section 1 (Introduction):
    Explains Bayesian-Torch vs Laplace: SVI during training vs post-hoc.
  
  Section 2 (Imports):
    Imports numpy, torch, nn, optim, plt, dnn_to_bnn, get_kl_loss.
  
  Section 3 (Data Setup):
    Loads sinusoidal data with sigma=0.3.
    150 train, 500 test points. 1000 epochs each phase, 100 MC samples.
  
  Section 4 (MAP Training):
    Network: Linear(1,50)->Tanh->Linear(50,1).
    Adam, MSE loss. Final MSE = 0.074138.
  
  Section 5 (Convert to BNN):
    bnn_prior_parameters with prior_mu=0, prior_sigma=1,
    posterior_mu_init=0, posterior_rho_init=-3,
    type="Flipout", moped_enable=True, moped_delta=0.5.
    dnn_to_bnn(model_bnn, bnn_prior_parameters)
  
  Section 6 (BNN Fine-tuning):
    ELBO loss: MSE + KL/batch_size.
    Adam lr=1e-3. 1000 epochs.
    Final ELBO=0.786689, KL=8.439800.
  
  Section 7 (MC Sampling Inference):
    100 forward passes. Predictive mean and std.
    Epistemic std=0.972, Aleatoric std=0.300, Total std=1.018.
  
  Section 8 (Visualizations):
    2x2 subplots: predictions+uncertainty, MAP loss, BNN ELBO+KL, uncertainty decomposition.
  
  Section 9 (Results Summary):
    Prints comparison table, uncertainty stats.
  
  Section 10 (Advanced Concepts):
    Explanation of Flipout, MOPED, ELBO.

KEY METRICS
  MAP MSE Loss: 0.074138
  BNN ELBO Loss: 0.786689
  KL Divergence: 8.439800
  Epistemic std: 0.972 (model uncertainty, varies with input)
  Aleatoric std: 0.300 (data noise, constant)
  Total std: 1.018 (combined)

RESULTS
  BNN captures both epistemic and aleatoric uncertainty.
  Epistemic uncertainty highest in extrapolation regions.
  Aleatoric uncertainty matches known noise level.
  Bayesian-Torch shows higher epistemic uncertainty than Laplace (0.97 vs ~0.05).

BAYESIAN-TORCH IMPLEMENTATION
  Two-phase: MAP pretrain then BNN fine-tune.
  dnn_to_bnn(model, params) - converts deterministic layers to Bayesian.
  get_kl_loss(model) - computes KL divergence for ELBO.
  Training: loss = mse + kl / batch_size
  Prediction: multiple stochastic forward passes averaged.
  MC samples: 100 for uncertainty estimation.

KEY METRICS
  MSE: Mean Squared Error (point accuracy)

  NLL: Negative Log-Likelihood (probabilistic quality)

  RMSE comparable between methods.
  Laplace 12x faster training and 50x faster ID inference than Bayesian-Torch.

LAPLACE IMPLEMENTATION

Location: ./two_moons_bayesian.ipynb
================================================================================

PURPOSE AND OBJECTIVES
  BNN for Two Moons classification using bayesian-torch.
  Compares Flipout vs Bayes-by-Backprop (BBB/Reparameterization).
  Mirrors the Laplace baseline setup for equitable comparison.

SECTION BREAKDOWN
  
  Cell 1 (Imports and Setup):
    os, torch, nn, optim, numpy, matplotlib, sklearn (make_moons, train_test_split,
    StandardScaler), TensorDataset, DataLoader.
    bayesian_torch: dnn_to_bnn, get_kl_loss.
    GPU check, LaTeX-compatible plot formatting.
    Creates ../figures directory.
  
  Cell 2 (Dataset Generation):
    10,000 Two Moons samples, noise=0.3, random_state=42.
    StandardScaler normalization.
    60/20/20 train/val/test split (note: val is created but dont seem used in
    the visible code except in DataLoaders).
    DataLoaders: batch_size=32 train, 64 val/test.
  
  Cell 3 (Visualization Helpers):
    plot_boundary(X_data, y_data, title): Decision boundary with contourf, contour,
    scatter. Returns cf, probs.
    uncertainty_map(X_data, y_data, title): Epistemic uncertainty as 1-2*|prob-0.5|.
  
  Cell 4 (Model Architecture and Training):
    TinyMLP: 2->64->Tanh->64->Tanh->2 (matches Two Moons Laplace notebook).
    train_bnn(model_type):
      - Creates model, sets bnn_prior_parameters
      - prior_mu=0, prior_sigma=1, posterior_mu_init=0, posterior_rho_init=-3
      - type: "Flipout" or "Reparameterization"
      - moped_enable: False (different from other notebooks)
      - dnn_to_bnn(model, params)
      - CrossEntropyLoss, Adam lr=5e-3, 20 epochs
      - Loss: nll_loss + kl_loss / num_samples
    Trains both model_flipout and model_bbb.
  
  Cell 5 (Prediction Wrapper):
    bnn_predict(X_np, model, n_samples=30):
      - Runs model 30 times, softmax, returns mean prob of class 1.
  
  Cell 6 (Decision Boundaries and Uncertainty Heatmaps):
    Side-by-side plots for Flipout vs BBB:
      - Decision boundaries (P(class 1))
      - Uncertainty heatmaps
    Saves: ../figures/bayesian_torch_boundary.png
    Saves: ../figures/bayesian_torch_uncertainty.png
  
  Cell 7 (Analysis Distributions):
    get_confidence_and_uncertainty(model, n_samples=30):
      Mean probs from MC, confidence = max prob, uncertainty = 1 - confidence.
    Three-panel figure:
      1. Confidence distributions (histogram)
      2. Flipout vs BBB confidence scatter
      3. Uncertainty distributions (histogram)
    Saves: ../figures/bayesian_torch_analysis.png
  
  Cell 8 (Comprehensive UQ Metrics):
    Imports pandas, time, sklearn.metrics (precision, recall, f1, roc_auc).
    expected_calibration_error(probs, labels, n_bins=15):
      ECE = sum |acc_k - conf_k| * n_k / N
    evaluate_uq_metrics(model, model_name, n_samples=50):
      Runs 50 MC samples.
      Metrics computed:
        - Accuracy: mean(predicted == true)
        - NLL: -log(mean_probs[true_class])
        - Brier Score: mean((probs - onehot)^2)
        - ECE: Expected Calibration Error
        - ROC-AUC
        - Precision, Recall, F1
        - Mean/Median Confidence
        - Predictive Std (mean, median, std)
        - CI95 Width: 95% confidence interval width
        - Uncertainty decomposition:
          Total = H[E[p(y|x)]] (entropy of mean prob)
          Aleatoric = E[H[p(y|x)]] (mean entropy across MC)
          Epistemic = Total - Aleatoric (mutual information)
        - Inference Time
    Evaluates both models.
    Creates DataFrame, exports to CSV (twomoons_bayesian_torch_metrics.csv).
    Creates LaTeX table.
    Saves metrics table figure: ../figures/bayesian_torch_metrics_table.png
  
  Cell 9 (Calibration Reliability Diagram):
    reliability_diagram(probs, labels, ax):
      Plots confidence vs accuracy per bin.
    Two models on same plot with ECE annotations.
    Saves: ../figures/bayesian_torch_reliability.png
  
  Cell 10 (Predictive Std Spatial Maps):
    get_std_map: Contourf of std(P(class=1)) across grid.
    bnn_predict_std: std across MC samples.
    Two side-by-side maps (Flipout vs BBB).
    Saves: ../figures/bayesian_torch_std_map.png
  
  Cell 11 (Summary Print):
    Prints all metrics for both models.

LIBRARIES
  torch: NN modules, training
  sklearn.datasets.make_moons: Dataset
  sklearn.model_selection.train_test_split: Split
  sklearn.preprocessing.StandardScaler: Normalization
  sklearn.metrics: precision, recall, f1, roc_auc
  numpy: Computation
  pandas: DataFrame, CSV
  matplotlib: All visualizations
  bayesian_torch: dnn_to_bnn, get_kl_loss
  time, os

KEY METRICS
  Accuracy: Fraction correct
  NLL: Negative log likelihood of true class
  Brier Score: MSE of predicted probabilities vs one-hot
  ECE: Expected Calibration Error
  ROC-AUC: Area under ROC curve
  Precision, Recall, F1
  Predictive Std: Std of MC predictions
  CI95 Width: 95% confidence interval
  Uncertainty Decomposition:
    Total = H[E[p]]
    Aleatoric = E[H[p]]
    Epistemic = Total - Aleatoric (mutual information)

RESULTS
  Both Flipout and BBB produce comparable accuracy.
  Flipout tends to produce more conservative uncertainty.
  Uncertainty heatmaps show higher uncertainty around decision boundary.
  Flipout vs BBB differences visible in confidence distributions.
  Proper uncertainty decomposition (epistemic vs aleatoric).

BAYESIAN-TORCH IMPLEMENTATION
  Unlike other notebooks, moped_enable=False.
  Two SVI types compared:
    - Flipout: Low-variance gradient estimator
    - Reparameterization (BBB): Standard reparameterization trick
  Combined loss: nll + kl / num_samples
  Monte Carlo sampling with n_samples=30 for inference, 50 for metrics.
