\section{Introduction}
\label{sec:intro}

Deep Learning finds use practically everywhere. Standard Neural Networks are
trained on given datasets in a frequentist maner, and their outputs are not
guaranteed to be true. This and the fact that the parameters set during training
are deterministic leads to over-confidence. Bayesian Deep Learning (BDL) addresses this
by replacing a deterministic weight estimate with a posterior distribution
$p(\btheta \mid \cD)$, propagating weight uncertainty into calibrated predictive distributions.
This report compares two PyTorch libraries implementing complementary Bayesian Neural Networks (BNNs) paradigms:
\begin{itemize}[leftmargin=*]
	\item \texttt{bayesian-torch}~\citep{intel2021bayesiantorch}, a
	      Bayesian by design library from Intel Labs implementing mean field
	      Variational Inference via Flipout~\citep{wen2018flipout} and
	      Bayes by Backprop~\citep{blundell2015weight}.
	\item \texttt{laplace-torch}~\citep{daxberger2021laplace,aleximmer2024laplace},
	      a library that allows applying the Laplace Approximation to any
	      pre trained model without modifying its training loop.
\end{itemize}

Experiments span three settings: two toy datasets, one is a regression
experiment, another a classification one, as well as a repli cation of the PovertyMap experiment done by Daxberger et al.~\citep{daxberger2021laplace}.
Full metric tables and figure galleries for completed experiments are in the Appendix~\ref{sec:app}.

\section{Theoretical Background}
\label{sec:theory}

\textbf{Neural Networks (NNs)~\citep{goan2020bayesian}.} A NN is a function approximator composed of layers of
interconnected neurons. There are multiple architectures, here we discuss the basis, the Multi-Layer
Perceptron (MLP), consisting of an input layer, one or more hidden layers, and
an output layer. The network is parameterized by the set $\btheta = \{\mathbf{W}^{(l)}, \mathbf{b}^{(l)}\}_{l=1}^{L}$,
where $\mathbf{W}^{(l)}$ and $\mathbf{b}^{(l)}$ are the weight matrix and bias vector for layer $l$, respectively.
Each neuron $i$ in layer $l$ computes a weighted sum of the activations from the previous layer, denoted
$\mathbf{h}^{(l-1)}$, passed through a nonlinear activation function $\sigma$:\begin{equation}h_i^{(l)} =
	\sigma\left(\sum_j w_{ij}^{(l)} h_j^{(l-1)} + b_i^{(l)}\right),\end{equation}where $w_{ij}^{(l)}$ denotes the element
in the $i$-th row and $j$-th column of $\mathbf{W}^{(l)}$.

Training minimizes a loss function $\mathcal{L}(\btheta)$ (e.g., mean squared
error, cross-entropy) via backpropagation and
gradient-based optimization (e.g., SGD, Adam). This is a frequentist setting, where the parameters are point estimates, and 
their values get updated iteratively during this process. 

The libraries discussed in this report, allow implementations in the various architectures, like
Convolutional Neural Networks (CNNs), Recurrent Neural Networks (RNNs) and Transformers.

\textbf{Bayesian Neural Networks (BNNs)~\citep{goan2020bayesian,murphy2023pml}.} In Bayesian Deep Learning (BDL), weights and biases are handled as 
random variables, and the goal is to infer their distribution given the data we have seen. Given the training dataset $\cD = \{(\bm{x}_n, y_n)\}
_{n=1}^{N}$ and network $f_{\btheta}$, the posterior distribution is \begin{equation}p(\btheta \mid \cD) = 
	\frac{p(\cD|\btheta)\,p(\btheta)}{p(\cD)}. \end{equation}
The evidence (or marginal likelihood), \begin{equation}p(\cD) = \int p(\cD|\btheta)\,p(\btheta)\,\mathrm{d}\btheta\label{eq:marginal_likelihood}\end{equation}
is intractable for modern DNNs. The prior $p(\btheta)$ encodes the distribution of the parameters before seeing the data. 
Initializing it depends on the characteristics of the problem, Gaussian priors $p(\btheta)=\cN(\bm{0},\tau^{-1}\mathbf{I})$ are common,
but sparsity promoting priors can also be used. We will see that methods like grid search, as well as marginal likelihood
\eqref{eq:marginal_likelihood} optimization, can be used to learn the prior.

This approach to NNs allows us to perform predictions by calculating the expected value of a given function $f(\btheta)$ under the posterior distribution:
\begin{equation}
    \mathbb{E}_{p(\btheta|\cD)}[f(\btheta)]
    = \int f(\btheta)\,p(\btheta|\cD)\,\mathrm{d}\btheta.
\end{equation}
One can obtain the expected value of the output of the network for a given input $\bm{x}^*$ by setting $f(\btheta) = p(y^*|\bm{x}^*, \btheta)$:
\begin{equation}
    \mathbb{E}_{p(\btheta|\cD)}[p(y^*|\bm{x}^*, \btheta)]
    = \int p(y^*|\bm{x}^*, \btheta)\,p(\btheta|\cD)\,\mathrm{d}\btheta.
\end{equation}
This integral is also intractable for modern NNs, which leads to the need of approximating it. 

There are multiple methods for approximating the posterior distribution, we will discuss two of them: Variational Inference (VI) and the Laplace Approximation (LA). These 
are implemented by \texttt{bayesian-torch}~\citep{intel2021bayesiantorch} and \texttt{laplace-torch}~\citep{daxberger2021laplace,aleximmer2024laplace}, respectively.

\subsection{Variational Inference (VI)~\citep{murphy2023pml,goan2020bayesian}}
VI treats the approximation as an optimization problem. We make assumptions about the structure
of the posterior distribution and then optimize the parameters $\bm\phi$ by using the Kullback-Leibler (KL) divergence to calculate the disimilarity of the assumed
posterior $q_{\bm\phi}(\btheta)$ and the true one $p(\btheta|\cD)$: 
\begin{equation}
    \KL\bigl(q_{\bm\phi}(\btheta)\,\|\,p(\btheta|\cD)\bigr)
    = \int q_{\bm\phi}(\btheta)\log\frac{q_{\bm\phi}(\btheta)}{p(\btheta|\cD)}\,\mathrm{d}\btheta.
    \label{eq:kl}
\end{equation} which can be expanded as:
\begin{multline}
    \KL\bigl(q_{\bm\phi}\,\|\,p(\btheta|\cD)\bigr)
    = \KL\bigl(q_{\bm\phi}\,\|\,p(\btheta)\bigr) \\
    - \mathbb{E}_{q}\!\bigl[\log p(\cD|\btheta)\bigr]
    + \log p(\cD).
    \label{eq:kl_expanded}
\end{multline}
Since $\log p(\cD)$ is constant w.r.t.\ $\bm\phi$, minimizing~\eqref{eq:kl} is
equivalent to maximising the Evidence Lower Bound (ELBO)~\citep{blundell2015weight,goan2020bayesian,murphy2023pml}:
\begin{equation}
    \ELBO(\bm\phi)
    = \mathbb{E}_{q}\!\bigl[\log p(\cD|\btheta)\bigr]
    - \KL\bigl(q_{\bm\phi}\,\|\,p(\btheta)\bigr).
    \label{eq:elbo}
\end{equation}
A common choice for $q_{\bm\phi}$ is a fully factorised Gaussian, placing an
independent univariate Gaussian over each weight~\footnote{For convenience, we will use weights for weights and biases from now on unless stated otherwise.}, where the mean captures the
point estimate and the variance captures its uncertainty.

\textbf{Bayes by Backprop (BBB).} Building on earlier variational treatments of neural networks~\citep{murphy2023pml},
\citet{blundell2015weight} showed that the reparameterisation of each weight as
\begin{equation}
    w_i = \mu_i + \sigma_i\,\varepsilon_i, \qquad \varepsilon_i\sim\cN(0,1),
\end{equation}
yields low-variance gradient estimates of~\eqref{eq:elbo} via backpropagation,
making VI practical for deep networks. Notably, the parameters obtained by
minimising~\eqref{eq:kl} differ in general from those found by the Laplace
approximation~\citep{murphy2023pml}. 

\textbf{Flipout\citep{wen2018flipout}: } reduce this variance by applying independent sign flip
matrices $\mathbf{r}_n,\mathbf{s}_n\in\{-1,+1\}^*$ to the shared
perturbation $\Delta\hat{\mathbf{W}}$ for each example $n$:
\begin{equation}
	\hat{\mathbf{W}}_n
	= \mathbf{W}_{\MAP} + \mathbf{s}_n \odot \Delta\hat{\mathbf{W}}
	\odot \mathbf{r}_n^{\!\top}.
\end{equation}

\textbf{MOPED Initialisation\citep{krishnan2020specifying}:} Training mean field BNNs from random initialisations is fragile.
\texttt{bayesian-torch}~\citep{intel2021bayesiantorch} addresses this via
MOPED: the posterior means are warm started from a
pre trained MAP checkpoint and the prior scale is set proportionally:
\begin{equation}
	\mu_i^{(0)} = \theta_{\MAP}^{(i)}, \qquad
	\sigma_i^{\text{prior}} = \delta\,|\theta_{\MAP}^{(i)}|, \quad \delta=0.5.
\end{equation}

\textbf{Accuracy vs Uncertainty Calibration (AvUC)\citep{krishnan2020avuc} :} Standard ELBO training minimises NLL but does not explicitly calibrate the
relationship between confidence and accuracy.
The
Accuracy vs Uncertainty Calibration loss, implemented in
\texttt{bayesian-torch}~\citep{intel2021bayesiantorch}, adds a direct
penalty for miscalibrated confidence.

Each prediction in a mini batch falls into one of four quadrants, split by
whether it is Accurate (A) or Inaccurate (I), and whether the model's
predictive uncertainty is Certain (C, below a threshold) or Uncertain (U,
above it): $n_{AC}$, $n_{AU}$, $n_{IC}$, $n_{IU}$ count samples in each of
the four. The AvUC loss aggregates the fractions of samples in the two
bad quadrants~\citep{intel2021bayesiantorch}:
\begin{equation}
	\mathcal{L}_{\mathrm{AvUC}}
	= \underbrace{\frac{n_{AU}}{n_{AU}+n_{AC}}}_{\text{over uncertain among correct}}
	+ \underbrace{\frac{n_{IC}}{n_{IC}+n_{IU}}}_{\text{overconfident among wrong}},
	\label{eq:avuc}
\end{equation}
counted within the current mini batch.
Each term lies in $[0,1]$; both are zero when calibration is perfect.

\subsection{Laplace Approximation}
\label{sec:theory:la}

The LA~\citep{daxberger2021laplace} builds a Gaussian posterior around
$\btheta_{\MAP}$ via second order Taylor expansion:
\begin{multline}
	p(\btheta|\cD) \approx \cN\!\bigl(\btheta;\,\btheta_{\MAP},\,\mathbf{H}^{-1}\bigr), \\
	\mathbf{H} = -\nabla^2\log p(\btheta_{\MAP}|\cD).
\end{multline}
$\mathbf{H}^{-1}$ is only a valid covariance if $\mathbf{H}$ is positive
definite, which the exact Hessian is not guaranteed to be for a general
NN~\citep{daxberger2021laplace}. In practice $\mathbf{H}$ is replaced by a
provably positive semi-definite curvature approximation, the Fisher
information matrix or the Generalised Gauss-Newton (GGN) matrix, further
factorised as Full, Kronecker-factored (KFAC), or Diagonal to stay
tractable~\citep{daxberger2021laplace}; this is the Hessian structure
referenced throughout the Results.

\paragraph{Marginal likelihood tuning.}
The prior precision $\tau$ is selected by maximising the log evidence:
\begin{multline}
	\log p(\cD)
	\approx \log p(\cD|\btheta_{\MAP})
	+ \log p(\btheta_{\MAP}) \\
	+ \tfrac{P}{2}\log 2\pi
	- \tfrac{1}{2}\log\det\mathbf{H},
	\label{eq:marglik}
\end{multline}
which is differentiable with respect to $\tau$ and requires no validation
data~\citep{daxberger2021laplace}. Grid search over
a discrete set of values on validation NLL is simpler but requires a
held out split.

\subsection{Uncertainty Quantification and Metrics}
\label{sec:theory:unc_decomp}

For MC based BNNs, the total predictive uncertainty can be decomposed into
two orthogonal components~\citep{goan2020bayesian}:
\begin{align}
	\text{Total}     & = H\!\left[\frac{1}{S}\sum_{s=1}^{S} p(y|f_{\btheta_s}(\bm{x}))\right], \\
	\text{Aleatoric} & = \frac{1}{S}\sum_{s=1}^{S} H\!\left[p(y|f_{\btheta_s}(\bm{x}))\right], \\
	\text{Epistemic} & = \text{Total} - \text{Aleatoric}
	= I\!\left(y;\btheta\,|\,\bm{x},\cD\right),
	\label{eq:mi}
\end{align}

\label{sec:metrics}

\paragraph{Negative Log-Likelihood (NLL).}
For classification, the negative log-likelihood of the true class,
$\mathrm{NLL}=-\frac{1}{N}\sum_n\log\hat{p}_{n,y_n}$. For regression, the
negative log-likelihood under the predictive Gaussian,
$\mathrm{NLL}=\frac{1}{N}\sum_n\left[\frac{1}{2}\log(2\pi\sigma_n^2)+\frac{(y_n-\mu_n)^2}{2\sigma_n^2}\right]$,
using the combined predictive std $\sigma_n=\sigma_{\text{total},n}$ from
Section~\ref{sec:imp:sinusoid}. Both reward calibrated, sharp predictive
distributions rather than point accuracy alone.

\paragraph{Brier Score (BS).}
$\mathrm{BS}=\frac{1}{N}\sum_n\sum_c(\hat{p}_{nc}-\mathbf{1}[y_n=c])^2$;
bounded and less sensitive to extreme probabilities than NLL.

\paragraph{Expected Calibration Error (ECE).}
Confidences $\max_c\hat p_{nc}$ are partitioned into $B=15$ equal-width bins
$S_1,\dots,S_B$; $\mathrm{ECE}=\sum_{b=1}^{B}\frac{|S_b|}{N}\left|\mathrm{acc}(S_b)-\mathrm{conf}(S_b)\right|$,
the sample-weighted gap between empirical accuracy and mean confidence in
each bin. Used for the classification (Two Moons) results.

\paragraph{Root Mean Squared Error (RMSE).}
$\mathrm{RMSE}=\sqrt{\frac{1}{N}\sum_n(y_n-\mu_n)^2}$, the point-prediction
error used for the regression (Sinusoid, PovertyMap) results.

\paragraph{Regression Calibration Error.}
The regression analogue of ECE, reported by Laplace Redux~\citep{daxberger2021laplace}
(Fig.\ 6/10) as a rescaled version of the calibration diagnostic of
\citet{kuleshov2018calibrated}: for a grid of nominal levels $p\in[0,1]$, the
predictive CDF $\Phi((y-\mu)/\sigma)$ is evaluated at each true value, and
the fraction of points with $\mathrm{CDF}(y)\leq p$ is compared against $p$;
the calibration error is the sample size times the mean squared gap between
the two, a scaling not present in Kuleshov et al.'s own definition. Used for
all regression (Sinusoid, PovertyMap) results.

\paragraph{Epistemic uncertainty OOD maps.}
Mutual information $I(y;\btheta|\bm{x},\cD)$ estimated via
equation~\eqref{eq:mi} with $S=50$ MC samples, mapped over a grid of inputs
extending beyond the training data. Used to visualise where each method's
epistemic uncertainty grows on Two Moons (Section~\ref{sec:results}) and how
it grows with $x$ outside the training range on Sinusoid.

\section{The Implementations}
\label{sec:imp}

We consider one classification and two regression experiments. Different 
possible configurations of BNNs with two libraries, 
\texttt{bayesian-torch}~\citep{intel2021bayesiantorch} and 
\texttt{laplace-torch}~\citep{daxberger2021laplace,aleximmer2024laplace}, are 
implemented and compared for the classification and regression 
datasets.

For classification, we use the Two Moons dataset, which consists of an arbitrary 
2D distribution of two interleaved half crescents. For regression, a 1D sinusoidal 
dataset, which is taken from the regression example provided in the 
\texttt{laplace-torch}~\citep{aleximmer2024laplace} repository. Finally, we replicate and expand on the
the PovertyMap experiment done by Daxberger et al.~\citep{daxberger2021laplace}, 
which consists of a regression task on satellite imagery. 

We provide jupyter notebooks using five seeds for generating the Two Moons and Sinusoidal datasets. 
For \texttt{laplace-torch}, we use the high level API, as well as a lower level one where we implement the training loop available in the examples provided in the repository.
The different configurations of \texttt{bayesian-torch}, using both Flipout and BBB, with and without MOPED initialisation, and with ELBO and AvUC training, are implemented.
The full configuration
grids are shown in Tables~\ref{tab:la_variants} and~\ref{tab:bt_variants}. We want to explore how 
the different configurations affect the performance of the BNNs, and how they compare to each other, while
assessing how well calibrated they are, i.e., how accurately they reflect the true uncertainty.
Because the approaches can be so varied, we also explore alternatives by choosing different parameters, e.g. 
different deltas for MOPED, different (fixed/learned) priors, etc. These results can be seen in the nootebooks
provided, but their actual results will be shown in the Appendix~\ref{sec:app}.

All possible variants are not always considered, the experiments were not designed in parallel, therefore some results
affect the setup of others. For exmaple, we can see a poor performance in uncertainty quantification for Diaganol approximations
in LA, so we dont consider them for some experiments, in particular we will show a focus on KFCA as it is recommended per the 
findings in \citet{daxberger2021laplace}, which should perform comparably to Full LA, but with a lower computational cost.

In an effort to avoid duplicated code, multiple functions are implmented in the
\texttt{shared} module, which is imported in the notebooks.

\textbf{The \texttt{laplace-torch} Interface. }
\label{sec:imp:la_api}As introduced in Section~\ref{sec:theory:la}, the LA is applied across the Two Moons and Sinusoidal notebooks through the same high level \texttt{laplace-torch}~\citep{daxberger2021laplace,aleximmer2024laplace} interface, built around a network already trained to a MAP solution $\btheta_{\MAP}$. Constructing the approximation is a single call,
\begin{center}
\texttt{Laplace(model, likelihood, subset\_of\_weights, hessian\_structure)},
\end{center}
where \texttt{likelihood} is set to \texttt{"classification"} or \texttt{"regression"} depending on the observation model. Calling \texttt{.fit(train\_loader)} accumulates the curvature estimate $\mathbf{H}$ from the training data. Predictions are then obtained by calling the fitted object directly, \texttt{la(X, pred\_type="glm", ...)}, which linearises the network around $\btheta_{\MAP}$ and returns a closed form Gaussian over the network output.

\textbf{The \texttt{bayesian-torch} Interface. }
\label{sec:imp:bt_api}
The \texttt{bayesian-torch}~\citep{intel2021bayesiantorch} variants are built by converting an already instantiated network in place,
\begin{center}
\texttt{dnn\_to\_bnn(net, \{prior\_mu, prior\_sigma, posterior\_mu\_init, posterior\_rho\_init, type, moped\_enable, moped\_delta\})},
\end{center}
where \texttt{type} selects Flipout or Reparameterization (BBB) layers, and \texttt{moped\_enable} triggers the MOPED warm start once \texttt{net} already holds the MAP weights it initialises from. Unlike \texttt{laplace-torch}'s single \texttt{.fit()} call, training is a manual loop: every step adds \texttt{get\_kl\_loss(net)/batch\_size} to the task loss, and AvUC variants further add the calibration penalty of Equation~\eqref{eq:avuc}, computed on the mean of several MC logit samples rather than a single forward pass.

\subsection{Two Moons}

Two crescent moons are generated with the \texttt{sklearn.datasets.make\_moons} function, with 10000 samples
split into 60 / 20 / 20 for training, validation and test sets, respectively. The dataset is generated with a
noise of 0.3.

\paragraph{GLM predictive and the probit link.} The GLM predictive yields a Gaussian distribution over the network's logits, which has no closed form once passed through a sigmoid to obtain class probabilities. \texttt{laplace-torch} approximates this integral with the probit link, \texttt{link\_approx="probit"}.

\paragraph{MC softmax predictive.} \texttt{bayesian-torch} has no closed form linearisation to fall back on: each of the weight samples from \texttt{bt\_mc\_forward} is passed through a softmax, and the resulting probability vectors are averaged to obtain the class probabilities.

\paragraph{Visualisations.} For each variant, a representative decision boundary is plotted from the last seed's fitted model. Epistemic uncertainty is visualised as the per pixel mutual information from Equation~\eqref{eq:mi}, mapped over a grid extending beyond the training data using $S=50$ predictive samples per point and averaged across seeds. Reliability diagrams (confidence vs.\ empirical accuracy) are likewise averaged across seeds.

\subsection{Sinusoid}
\label{sec:imp:sinusoid}

\paragraph{Closed form regression predictive.} Unlike classification, the closed form
Gaussian from Section~\ref{sec:imp:la_api} is used directly here, with no probit-style
approximation needed: \texttt{la\_predict} returns the mean and epistemic standard
deviation at each point straight from the linearisation.

\paragraph{Aleatoric noise.} Neither the closed form Gaussian nor the \texttt{bayesian-torch}
MC average captures observation noise on its own. For \texttt{adam\_loop} variants,
\texttt{laplace-torch} jointly tunes \texttt{sigma\_noise} with the prior precision; for
\texttt{marglik}/\texttt{gridsearch} variants it is instead fixed to the MAP model's
residual standard deviation, and only the prior precision is tuned. \texttt{bayesian-torch}
fits \texttt{sigma\_noise} separately with \texttt{optimize\_noise\_std\_bt}, minimising
Gaussian NLL against a validation set. The two are combined as
$\sigma_{\text{total}}^2 = \sigma_{\text{epistemic}}^2 + \sigma_{\text{aleatoric}}^2$
for every reported metric and figure.

\paragraph{Visualisations.} For each variant, the mean prediction is plotted with total,
epistemic, and cross-seed variability bands, averaged over the five seeds, alongside the
true $\sin(x)$ curve. Epistemic uncertainty is also plotted against $x$ on its own, showing
how it grows once $x$ leaves the training range $[0,8]$. Calibration is assessed with the
regression calibration error defined in Section~\ref{sec:metrics}.


\textbf{\texttt{laplace-torch} regression example: }We base the first approach on the dataset provided in the library. The dataset is split into 150 samples for training, 
50 for validation, and 250 for ID testing, while also providing the same amount for OD testing. This dataset is presented in the library without validation set, it 
serves to show the power of optimazing with the Marginal Likelihood approach, when grid search is not possible because of a lack of said set. 

\textbf{Second set: }Because of the big limitation and the specificity of the use case from the previous set, we aim to provide a more even experiment to compare 
\texttt{laplace-torch} and \texttt{bayesian-torch}. We generate a 1D sinusoidal dataset with 1200 samples, split into 600 / 200 for training and validation, respectively,
as well as 200 samples for ID and OOD testing sets each.


\subsection{PovertyMap}

The PovertyMap dataset is part of the WILDS benchmark\footnote{https://wilds.stanford.edu/}.
It consists of satellite imagery of Africa, with the wealth index of the area as the target variable. It provides 5 folds, meaning that for the whole dataset 5 distinct 
combinations of different  splits with different countries provided in the training, validation, and test sets are provided, with given ID and OOD splits for testing.
The paper that presents \texttt{laplace-torch}~\citep{daxberger2021laplace} uses the WILDS benchmark to compare the perfomance of the library against other methods of 
implementing BNNs, and performing uncertainty quantification on NNs. We expand on it by adding the \texttt{bayesian-torch} library to the comparison, as only Deep Ensambles
are compared against the LA and the afore mentioned library is used in comparsion with other non-regression experiments in the same paper.

\section{Discussion}
\label{sec:discussion}

MOPED is a geometric anchor. The BBB scratch AvUC failure demonstrates that AvUC calibration alone is not sufficient.
Under marglik, full matrix GGN curvature is poorly conditioned and selects pathological prior precisions.
All weights LA marglik variants retain some OOD epistemic sensitivity, while last layer LA and all SVI variants collapse to near zero outside the boundary.
